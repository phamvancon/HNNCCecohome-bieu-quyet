Trạng Thái Đồng Bộ Đám Mây Firebase (iOS Safe & Online)

Hệ thống tích hợp đồng bộ dữ liệu cư dân và phiếu đánh giá trực tuyến qua Firebase Cloud Firestore, kết hợp bộ nhớ đệm IndexedDB và LocalStorage để hoạt động trơn tru trên mọi thiết bị di động và iPhone.

// Quy tắc Cloud Firestore khuyên dùng:

rules_version = '2';

service cloud.firestore {

  match /databases/{database}/documents {

    match /{document=**} {

      allow read, write: if true;

    }

  }

}
